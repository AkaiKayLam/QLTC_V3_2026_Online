# Tài chính cá nhân offline – v4.4

## Thay đổi mới
- Gộp tab **Sao lưu - Cài đặt**
- Sao lưu Google Drive **thủ công**, **ghi đè** file cũ (`TaiChinhCaNhan_latest.pfbackup`) → không tạo nhiều bản
- Danh mục mẹ (nhóm): chữ đen, to, đậm; danh mục con: chữ nhỏ, màu xám
- Hỗ trợ **vân tay / Face ID** (WebAuthn) để mở khóa (vẫn cần PIN sau khi xác thực sinh trắc học)
- Các tính năng trước: phân trang, tìm kiếm, chặn ngày tương lai, cảnh báo số dư âm, chuyển khoản, vay nợ, thống kê, v.v.

## Lưu ý sinh trắc học
- Chỉ hoạt động trên HTTPS hoặc localhost, thiết bị có vân tay/Face ID, trình duyệt hỗ trợ WebAuthn.
- Cần mở khóa bằng PIN ít nhất một lần rồi vào tab Sao lưu - Cài đặt → Đăng ký vân tay / Face ID.
