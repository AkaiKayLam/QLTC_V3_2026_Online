Bấm nút khi bạn muốn sao lưu. File tải về máy.

Đăng nhập Google & sao lưu Drive (ghi đè)

Sao lưu thủ công: mỗi lần bấm sẽ ghi đè file cũ trên Drive (không tạo nhiều bản, tiết kiệm dung lượng). Cần tạo OAuth Client ID trên Google Cloud Console.

Chưa đăng nhập

Hướng dẫn tạo Google Client ID
  1. Vào Google Cloud Console
  2. Tạo project → bật Google Drive API
  3. Credentials → Create Credentials → OAuth client ID → Web application
  4. Authorized JavaScript origins: thêm URL app (https://...github.io hoặc http://localhost:...)
  5. Copy Client ID dán vào ô trên → Lưu Client ID → Đăng nhập Google
